Cortex AI Functions Used

🧠

CORTEX.COMPLETE (llama3.1-70b)

Evidence report generation, regulatory Q&A, investigation narratives. All responses grounded via RAG context injection.

LLM
📌

EMBED_TEXT_768 (e5-base-v2)

768-dimension vector embeddings on 18 regulatory chunks. Powers semantic similarity search for RAG retrieval.

Embeddings
📑

AI_EXTRACT

Structured field extraction from unstructured text. Pulls section numbers, dollar thresholds, regulatory citations, country lists from both regulatory docs and alert descriptions.

Document Processing
🏷

AI_CLASSIFY

Automatic topic categorization of regulatory chunks into AML_COMPLIANCE, TRANSACTION_MONITORING, CUSTOMER_DUE_DILIGENCE, INVESTIGATION_PROCEDURES, and more.

Classification
🔎

Cortex Search Service

Hybrid semantic + keyword search over the regulatory corpus. 1-hour target lag for auto-refresh. Powers the RAG pipeline for all agents.

Search
💰

Cortex Analyst (text-to-SQL)

Natural language to SQL via semantic view. 4 verified queries for alert lookup, risk scoring, structuring detection, high-risk wire analysis.

Guardrails & Governance

AI Guardrails

🔒
Input Validation

SQL injection blocking (DROP, DELETE, TRUNCATE), query length limits (1000 chars)

🎯
Topic Relevance

Warns when questions are outside risk/fraud/compliance domain

📈
Confidence Scoring

HIGH/MEDIUM/LOW confidence based on regulatory citation count in response

📖
RAG Grounding

LLM instructed to use ONLY provided regulatory context, flag uncertainty

⚠
Low Confidence Warning

Yellow warning when response lacks citations: "verify against source documents"

🛠
Error Handling

Graceful fallback on Cortex API errors with user-friendly messages

Data Governance

RBAC Roles

RISK_ANALYST — Full investigate + generate evidence

RISK_AUDITOR — Read-only access to all data + audit trail

PII Protection

Dynamic Masking: PII_MASK policy on FULL_NAME, EMAIL, PHONE

Semantic Tags: SNOWFLAKE.CORE.SEMANTIC_CATEGORY on all PII columns

RISK_AUDITOR sees: ***MASKED***

Audit Trail

COPILOT_AUDIT_LOG captures every AI interaction: action type, alert ID, query, RAG context, LLM response, user, timestamp

Human-in-the-Loop

Internal policy requires all AI-generated content reviewed by human investigator before SAR filing
