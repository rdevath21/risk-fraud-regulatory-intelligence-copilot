Emergency Shortcuts

If something fails during recording:
  • CoCo not responding: Switch to Streamlit and demo from there. Say "Let me show the same workflow in the Streamlit interface."
  • Streamlit error: Stay in CoCo and run SQL queries directly. All data is live.
  • Agent not found: Use SHOW AGENTS IN SCHEMA RISK_COPILOT.PUBLIC in CoCo to verify, then retry.
  • Search returns 0 results: Try a different query like "What is AML compliance?" - this always returns results from the regulatory chunks.
